# 户型装修设计

中文 | [English](README.en.md)

纯前端的户型装修设计工具：在 2D 平面图上摆放家具、拆改墙体、测量尺寸，一键切换到 Three.js 3D 场景，可以鸟瞰，也可以第一人称漫游。整个应用就是一个 `index.html`，无需构建，打开即用。

## 当前户型：IMG_0914

默认户型已按提供的 IMG_0914 照片重建：四室两厅三卫，层高经确认采用 3.3 m，北侧套房为保姆房（带独立卫浴），主卧侧窗为两扇外开窗，包括右上斜向双扇入户门、南侧弧窗卧室和两个阳台。已标注尺寸优先；未标注的墙厚、门窗宽度和弧窗形状按图片比例估算，面积供布置参考。

照片未提供墙体结构属性：内墙使用 `u`（待核实），可通过「待核实墙」高亮查看，暂不支持直接拆除。外墙使用 `e`。

顶部「户型」下拉框可切换「我的户型 · 四室两厅三卫」、「示例」及「卫生间 · 1.8 × 1.7 m」。切换前自动保存当前布置，各户型的家具、房间名称、地面、拆墙和测量记录独立保存，刷新后恢复上次选择；2D / 3D 模式均支持切换。

点击「保存户型」会在浏览器中保存当前布置及完整户型快照。「文件 → 导出户型 JSON」导出墙体、门窗、房间、层高与当前布置；通过「导入户型 / 方案」可新增其他户型，相同户型恢复布置、结构不同则保留为新选项。旧版仅含布置的 JSON 仍可导入，并自动选择对应户型。

项目内的 `floorplans/img-0914.json` 是当前修正户型的完整备份（3.3 m、保姆房、两扇外开侧窗）；`floorplans/original.json` 备份原始户型。可直接导入这些文件。为支持直接双击打开 HTML，内置目录同时嵌入 `index.html` 的 `BUILTIN_PLANS`。

浏览器保存键：当前户型 `huxing-design-img-0914-v1`，原始户型沿用 `huxing-design-v1`；自定义户型目录使用 `huxing-custom-plans-v1`。导出格式为 `{format:"floorplan-3d", version:2, plan, state}`，其中 `state.planId` 标识布置所属户型。

户型坐标单位为 mm，原点取左侧主卧外墙中心线与最北侧墙中心线的交点。`WALLS` 的可选第六项是斜墙多边形；`WINS` 使用 `{a, b, t, sill, head}` 定义中心线端点、厚度（mm）及窗台/窗顶高度（m）。弧窗由连续窗段组成。

验证：`node --test tests/*.test.cjs`。

## 卫生间独立户型

`floorplans/bathroom-1800-1700.json` 保存净尺寸左右 1700 mm、上下 1800 mm 的卫生间，可从顶部户型列表直接选择。顶部淋浴深 730 mm，挡水条平面宽 70 mm，占纵坐标 730–800 mm，干区保持 1000 mm。下水管道左边缘距左墙 305 mm，管道中心距挡水条靠马桶一侧边缘 380 mm，因此中心纵坐标为 y=1180 mm。

上侧和右侧两面墙从地面起高 1000 mm 为砖墙并铺墙砖，1000–3300 mm 为玻璃。平面图显示玻璃边界，3D 显示下砖上玻璃；左侧和门侧保留实墙。

下水口直径按用户指定为 **130 mm**，故中心横坐标 **305 + 130/2 = 370 mm**，纵坐标 **1180 mm**。2D / 3D 只绘制地面圆形下水口，无中心线、十字或凸起管段；示意壁厚 3 mm。305 / 380 的定位尺寸标在下水口处。管道保持固定，马桶移动不会改变它的位置。

已加入独立可编辑的典型马桶模型（宽 366 × 深 700 × 高 698 mm），可拖动、旋转和修改宽深。尺寸参考科勒 NEW PATIO 产品目录，外形是通用示意，并非产品精确复刻。旧版没有马桶的保存会自动加入一只，后续移动和修改会分别保存。

瓷砖参照用户照片 `679.JPG`：浅灰米色 **800 × 400 mm**，墙面横向对缝，地面同向直铺。1700 mm 宽度暂排为左侧 100 mm 边砖 + 两块 800 mm 整砖，淋浴与干区的纵向砖缝对齐。按用户指定从门口整砖起铺，向挡水条依次排 400 + 400 + 200 mm；在挡水条处切开，保持同一砖网向淋浴区继续排 130 + 400 + 200 mm 至内墙。墙面每排高 400 mm，侧墙横向排 200 + 800 + 800 mm，顶排随 3.3 m 层高裁切。横向边砖尺寸、2 mm 砖缝和颜色为照片推定。2D 和 3D 共用 `floorLayout` 排砖数据；`wallTiles` 定义墙面砖缝起点。旧卫生间保存会升级瓷砖并保留家具位置和尺寸。

马桶尺寸来源：[科勒座便器目录](https://files.kohler.com.cn/book_files/contentPic/cid2/32.2024%E5%B9%B4%20%E5%BA%A7%E4%BE%BF%E5%99%A8%E5%8F%8A%E7%9B%96%E6%9D%BF.pdf)。下水口 130 mm、挡水条宽 70 mm 为用户指定。

右下门暂定 800 mm、右侧铰链向内开。左下角洗手台属性为宽 300 × 深 500 mm，龙头靠左墙，中心坐标 (250,1650) mm、旋转 270°，不显示常驻尺寸标注，选中后可查看及调整尺寸。旧保存升级尺寸、位置及朝向，后续编辑或删除会保留。挡水条高度暂定 50 mm；层高沿用 3.3 m。`annotations` 用于定位标注，墙数据第七项可指定低矮构件高度（米）。

## 功能

**2D 平面布置**
- 按原始户型 1:60 / 1:100 比例显示，尺寸单位 mm
- 从左侧家具库拖入 60 余种家具家电（卧室、客厅、餐厨、卫浴、家电、书房休闲）
- 拖动移动、旋转（Shift 自由角度）、调整尺寸，贴墙自动吸附
- 测量工具（靠近墙面自动吸附，Shift 锁定水平 / 垂直）
- 拆改非承重墙，承重墙单独标示
- 图层开关：尺寸标注、房间名、家具、网格、承重墙

**3D 场景**
- 鸟瞰、斜视、俯视多种视角，点击房间列表可飞到对应房间
- 漫游模式：桌面端 WASD + 鼠标，触屏设备用虚拟摇杆，可以点门开关
- 全高墙 / 剖切墙切换，日照时间滑块，夜景灯光
- 精细家具模型：柜门分缝与拉手、软包床头、带环境反射的金属与陶瓷材质等
- 在 3D 中也能选中、拖动家具，与 2D 方案实时同步

**方案与统计**
- 房间面积与套内使用面积自动统计
- 为每个房间更换地面材料（木地板、地砖、大理石、水磨石、地毯等），按面积加 5% 损耗估算造价
- 撤销 / 重做，方案自动保存在浏览器本地
- 中文 / English 界面切换（顶栏右侧按钮，默认中文，选择会记住）
- 导出 PNG 图片，导出 / 导入方案 JSON

## 手机使用

- 手机竖屏采用两行导航，横屏采用单行导航；户型切换、保存和 2D / 3D 始终可见。
- 「更多」包含测量、图层、撤销、视角、语言和文件操作；画布旁可直接缩放或适应窗口。
- 家具库、属性使用底部抽屉，点关闭或空白遮罩收起。点选家具添加后抽屉自动关闭，在画布中拖动摆放；选中后的底部工具条提供旋转、复制、删除和属性。
- 属性输入字号至少 16 px，按钮便于触摸；支持安全区域、可见高度与横竖屏变化。触屏设备降低 3D 像素比和阴影分辨率。
- 部署后使用手机访问同一网址即可；本地修改后需重新上传最新 `index.html`。

## 快速开始

```bash
git clone <仓库地址>
cd <仓库目录>
```

然后直接用浏览器打开 `index.html`。也可以起一个本地静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

> Three.js 通过 jsDelivr CDN 加载，首次打开 3D 场景需要联网。

## 从 GitHub 部署到 Netlify

仓库根目录的 `netlify.toml` 已配置构建与发布目录。Netlify 连接 GitHub 仓库后会自动读取配置：构建命令为 `mkdir -p dist && cp index.html dist/index.html`，发布目录为 `dist`。仅发布网站所需的 `index.html`，无需安装依赖。

在 Netlify 导入 GitHub 仓库并选择部署分支；若要保留已有网址，请在原项目中连接仓库。连接完成后，向所选分支推送新提交即可自动更新网站。浏览器本地保存的个人布置仍需另行导出 JSON 备份。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `T` | 切换 2D / 3D |
| `V` / `M` / `X` | 选择 / 测量 / 拆改墙体 |

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 2D 平面图用 SVG 绘制
- 3D 场景用 [Three.js](https://threejs.org/) r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- 数据保存在 `localStorage`

## 自定义户型

户型数据写在 `index.html` 里：

- `ROOMS`：房间多边形、名称、默认地面材料
- `WALLS` / `WINS`：墙体与窗洞
- `MATS`：地面材料名称与单价
- `LIB`：家具库（类型、名称、默认尺寸、颜色）
- `buildFurniture()`：各类家具的 3D 模型

改这些数据就能换成自己的户型。
